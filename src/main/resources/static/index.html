THE PROJECT

The ShopWise AI Project

ShopWise AI is an AI-powered shopping assistant designed to help users discover products based on their requirements and budget.

The application combines a Spring Boot backend, a MySQL product catalog, and an AI assistant to provide catalog-based shopping recommendations.

Product information comes from the actual catalog, including product names, categories, descriptions, and prices, instead of relying on made-up product data.

  • Java
  • Spring Boot
  • Spring AI
  • Ollama / Llama 3.2
  • MySQL
  • Spring Data JPA
  • REST APIs
  • HTML, CSS and JavaScript
  • Budget-aware search
  • Product comparison

WHAT IT OFFERS

Features

✦

AI Shopping Assistant

Users describe a need in plain language. Spring AI and a local Llama 3.2 model help interpret the request and reply in a shopping-assistant style.

₹

Budget-Aware Recommendations

When a budget is mentioned, the catalog can be filtered to products at or below that price so suggestions stay within range.

▣

MySQL Product Catalog

Product names, descriptions, prices, and categories are stored in MySQL and read through Spring Data JPA — not a hardcoded list.

⌕

Product Search

REST APIs support listing, category filters, and name search. The assistant can use the same catalog lookups while answering a chat request.

⇄

Product Comparison

Users can ask to compare items. The assistant retrieves the selected catalog records and bases the comparison on those fields.

✓

Catalog-Grounded Responses

The chat API also returns the matching products as structured data, so the UI can show real catalog cards next to the assistant’s answer.

How It Works

  1. 1 Tell Us What You Need

    The shopper types a need, such as a category or a budget.

  2. 2 AI understands Your Request

    The assistant reads the message and decides how to search the catalog.

  3. 3 Search the Product Catalog

    Spring Boot queries MySQL through the product APIs and tools.

  4. 4 Get Relevant Recommendations

    A written answer and catalog product cards are shown together.
